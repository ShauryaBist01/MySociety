# MySociety

My Society is a web-based Society Management Application developed using Python, Flask, SQLite, HTML, and CSS. The application is designed to simplify and digitalize the daily operations of residential societies by providing a centralized platform for society administrators and residents.

The system features role-based access for Society Presidents and Members, allowing them to manage their respective activities through dedicated dashboards. Key functionalities include member management, facility management, complaint registration and tracking, maintenance charge calculation, and payment status management.

By replacing manual record-keeping with an organized digital system, My Society improves transparency, reduces administrative workload, and enhances communication between residents and society management. The project demonstrates practical implementation of web development, database management, authentication, and CRUD operations to create an efficient and user-friendly residential management solution.
